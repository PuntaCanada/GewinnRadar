# GewinnRadar Familie 🎁

Privater Familien-Gewinnspiel-Assistent (Entwicklungsprojekt, **nicht produktiv**).

## Stand 21. November 2026
Dieses GitHub-Repository enthält zunächst ein sicheres, nicht produktives Grundgerüst. Das vollständige geprüfte v0.2-Starterpaket wurde separat als `gewinnradar-familie-v0.2-geprueft.zip` bereitgestellt; seine Übernahme in einzelne Repository-Dateien ist noch nicht abgeschlossen.

**Wichtig:** Das Repository ist derzeit auf GitHub **öffentlich** eingestellt. Keine realen personenbezogenen Daten, API-Keys, D1-Datenbank-IDs, E-Mail-Adressen oder Geheimnisse einchecken.

## Geplante Familienfunktionen
- Seniorenfreundlicher privater Bereich und persönliche Teilnahme-Häkchen.
- Separater Datenbestand je Benutzer; Tageshäkchen für Adventskalender.
- Von Menschen bestätigte seriöse Originalgewinnspiele mit Fristen und Datenschutzangaben.
- Automatische Linkprüfung mit vorsichtigem Umgang mit Bot-Sperren.
- Tägliche E-Mail-Erinnerungen ausschließlich nach Einwilligung.
- Keine automatische Teilnahme an externen Gewinnspielen.

## Sicherheitsfreigabe
Keine produktive Cloudflare-Bereitstellung, keine Registrierung, kein Mailversand. Freigabe erst nach getesteter Anmeldung, D1-Migration, Datenschutz-/Rechtsprüfung, korrekter Linkprüfung und ausdrücklicher Zustimmung des Betreibers.

Dieses Repository darf keine bestehenden PuntaCanada-Projekte verändern.
