# Adventskalender-Katalog – Eingangsprüfung

Dieses Verzeichnis ist eine **Vorbereitungsfläche, kein veröffentlichter Gewinnspielkatalog**.

- Ein Datensatz beschreibt eine originale Aktion im Jahr 2026 und ist zunächst immer `review`.
- Vor Freigabe: Impressum/Veranstalter, Original-URL, Teilnahmebedingungen, Datenschutz, deutsche Teilnahmeberechtigung, keine Kauf-/Abo-/Werbepflicht, Preis und Frist nachweisen.
- Tageskalender benötigen `daily: true`; der persönliche Teilnahmehaken wird pro Kalendertag gespeichert.
- Kein künstliches Auffüllen auf 50 oder 100 Einträge, keine älteren Kalender als aktuell kennzeichnen.
- Lösungen ausschließlich mit belastbaren Quellen und dokumentierter Unsicherheit.
- Kein Scraping persönlicher Daten und keine automatische Teilnahme.
- Die API erfordert explizite Admin-Freigabe und führt keine ungeprüften JSON-Dateien automatisch in die produktive Datenbank über.

Die Datei `candidate-template.json` ist ein **ungültiges Beispiel mit Platzhalteradressen**, keine echte Aktion.
